# Краткая инструкция (для себя)

## Что где
- Контроллер: A13, ESP32-S3-Zero. На этом ПК это COM7, USB serial `AC:27:6E:CE:BC:50`.
- Модель объекта: A09, ESP32-C3 с OLED. На этом ПК это COM8, USB serial `08:92:72:87:09:CC`.
- Провода: S3 `1` → C3 `4`, S3 `2` ← C3 `3`, `GND`–`GD`. Контакты `3V3` и `5V` не соединены.


## Ручное управление
Откройте два терминала с монитором порта: `idf.py -p COM7 monitor` и `idf.py -p COM8 monitor`.
`tools\bench.py` и монитор не должны одновременно держать один и тот же порт.

- **Контроллер:** `start 500`, `stop`, `reset`, `status`, `faults`, `faults clear`, `mute 2000`,
  `noise 3000`, `hang`, `reboot`.
- **Модель:** `set src 800`, `set dst 100`, `fault valve_stuck 1`, `fault pump_dead 1`,
  `fault leak 150`, `fault clear`, `mute 2000`, `noise 3000`, `hang`, `status`, `reboot`.

Что добавлено в v2, после трёхчасового окна:
- **`noise <ppm>`** портит случайные биты в отправляемых байтах. При 3000 ppm перекачка проходит, счётчики `crc_err` растут.
- **`hang`** вешает цикл платы. Через 1 с сторожевой таймер её перезагружает, в логе видно `reset_reason=TASK_WDT`.
- **`faults`** показывает журнал последних 8 неисправностей. Журнал хранится во flash и переживает перезагрузку.

Для видео хорошо смотрятся `noise 3000` на обеих платах и `hang` на модели.

**Светодиод S3:**
- белый — IDLE;
- жёлтый — CHECK;
- синий — перекачка;
- зелёный — завершено;
- мигающий красный — FAULT;
- мигающий фиолетовый — нет связи в IDLE.

**OLED на C3:**
- два бака с уровнями в мл;
- «P» — насос, закрашен, когда работает;
- «V» — клапан, с крестиком, когда закрыт;
- бегущие точки — поток;
- «FS» — модель в безопасном режиме, сама защитилась;
- «!» — введена неисправность.

## Что сказать в видео
См. [video_script.md](video_script.md). Главное:
- **Что реальное:** два микроконтроллера, связь по проводам, машина состояний, таймауты и защиты.
- **Что моделируется:** жидкость, насос, клапан, датчики. Неисправности тоже моделируются: они вводятся с консоли C3.
- **Инженерная трудность:** C3 перезагружается за ~120 мс, это быстрее таймаута в 300 мс. Только что загрузившаяся модель выполняла старую команду «насос ВКЛ». Исправлено взводом модели и флагом RESTARTED; на эту ошибку есть регрессионный тест.
